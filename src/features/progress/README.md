# Progress

Proof that the programme is working: body weight as a 7-day rolling average, training volume
over time, and personal records.

**Status:** placeholder. Built in **M7**.

One design constraint worth reading before building this: the raw daily scale reading is
misleading and demoralising in the first three weeks, because new training pulls water and
glycogen into muscle. **Lead with the rolling average, not the raw value.** See
[TRAINING_PROGRAM.md](../../../docs/TRAINING_PROGRAM.md) section 11.
